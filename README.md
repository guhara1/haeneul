# 해늘 (HAENEUL)

서울·경기·인천·부산 출장마사지·홈타이 안내 — **정적 사이트 산출물**입니다.

- 4,664쪽 (행정동 887 · 자리 2,661 · 롱테일 990 · 프로그램 5 · 되찾는 것 10)
- 이 저장소는 **생성기가 구운 결과물**입니다. 손으로 고치지 마십시오.
  생성기는 서버의 `/root/haeneul/gen` 에 있고, 다시 구우면 전체가 덮어쓰입니다.
- 클라우드플레어 페이지 연결용: 빌드 명령 없음 / 출력 디렉터리 `/` (저장소 루트)
- 주소가 정해지면 `gen/cfg.py` 의 `HOST` 를 고치고 다시 구워야 canonical·사이트맵이 따라옵니다.
